# СпортПрокат — FastAPI

Проект переписан с Flask на **FastAPI**. Сохранены SQLite, HTML-шаблоны, CSS/JS и демонстрационные данные.

## Запуск

1. Установите Python 3.10 или новее.
2. Откройте терминал в папке проекта.
3. Создайте виртуальное окружение (необязательно, но рекомендуется):

   ```bash
   python -m venv .venv
   ```

   Windows: `.venv\\Scripts\\activate`  
   Linux/macOS: `source .venv/bin/activate`

4. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

5. Запустите сервер:

   ```bash
   uvicorn main:app --reload
   ```

6. Откройте http://127.0.0.1:8000

Документация API: http://127.0.0.1:8000/docs  
Альтернативная документация: http://127.0.0.1:8000/redoc  
Проверка сервера: http://127.0.0.1:8000/health

## Структура

- `main.py` — FastAPI-приложение, маршруты, авторизация и бизнес-логика.
- `sportrent.db` — база SQLite.
- `templates/` — HTML-шаблоны Jinja2.
- `static/` — CSS, JavaScript и изображения.
- `requirements.txt` — зависимости.

## Основные возможности

- каталог, поиск и фильтрация оборудования;
- проверка доступности по датам;
- регистрация и вход;
- корзина и оформление бронирования;
- личный кабинет клиента;
- подтверждение, выдача и возврат аренды менеджером;
- складской учёт;
- управление оборудованием, категориями и пользователями;
- статистика;
- REST API: `/api/equipment`, `/api/categories`;
- автоматическая документация OpenAPI.

Для реального развёртывания задайте собственный `SECRET_KEY` в переменных окружения и используйте HTTPS.
